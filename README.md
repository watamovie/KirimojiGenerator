# KirimojiGenerator

静的なWebアプリでSVGから切り文字用のSTLを生成します。`index.html` をブラウザで開くだけで動作し、Cloudflare Pagesなどにそのままデプロイできます。

## 機能
- SVGをアップロードして指定厚みで押し出したSTLを生成
- 厚みは初期値3mmで変更可能
- 最大幅/高さを指定してリサイズ
- ストロークの一括削除
- 指定した塗り色のパスを削除

## 使い方
1. `index.html` をブラウザで開きます。
2. SVGファイルをアップロードします。
3. 必要に応じて厚み・仕上がりサイズ・削除オプションを設定します。
4. 「STLを生成」ボタンを押してダウンロードします。
