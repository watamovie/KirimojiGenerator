# Kirimoji Generator

Cloudflare Pages などでホストできる、SVG から立体の切り文字を生成して STL 形式でダウンロードできる静的 Web アプリです。

## 主な機能

- SVG ファイルのアップロード
- 塗り色の一覧表示と、任意の色で塗られた図形の削除
- ストローク属性の削除オプション
- 幅・高さ・厚み（初期値 3 mm）の指定による 3D モデル生成
- Three.js を利用した 3D プレビュー
- STL バイナリのダウンロード

## 使い方

1. `index.html` をブラウザで開き、SVG ファイルをアップロードします。
2. 必要に応じてストローク削除や塗り色の選択、仕上がりサイズ、厚みを設定します。
3. プレビューが自動的に更新されるので、3D 表示で確認します。
4. 問題なければ「STL をダウンロード」ボタンから書き出してください。

## 開発メモ

- Three.js のモジュールは CDN（jsDelivr）から読み込んでいます。ネットワークに接続できない環境では動作しません。
- SVG の塗り色削除は fill 属性／style の両方に対応しています。
- 仕上がり幅・高さを指定しない場合は、元の SVG サイズを維持します。
