# Kirimoji Generator

Cloudflare Pagesでホスト可能な静的サイトとして、SVGから切り文字向けのSTLを生成します。

## 使い方

1. `index.html` をブラウザで開きます。
2. SVGファイルを選択し、厚みと最大寸法 (XY方向) を指定します。
3. 必要に応じて以下のオプションを利用します。
   - SVG内のすべてのストロークを削除
   - 指定した色で塗られた図形を削除
4. 「STLを生成」を押すと変換が始まり、完了後にダウンロードリンクが表示されます。

## 主な機能

- 厚みの初期値は3mm。任意の厚みに変更可能。
- STL作成時にXY方向の最大寸法を指定してリサイズ。
- ストローク削除、特定の塗りの色を持つ図形の削除オプション。
- Three.jsのSVGLoaderとSTLExporterを利用したブラウザ内変換。

## デプロイ

Cloudflare Pagesなどの静的ホスティングに、リポジトリの内容をそのまま配置するだけで動作します。
