# Kirimoji Generator

Kirimoji Generator は、アップロードした SVG から厚み付きの立体を生成し、STL ファイルとしてダウンロードできる静的 Web アプリです。Cloudflare Pages などの静的ホスティングでそのまま公開できます。

## 主な機能

- SVG ファイルのアップロード
- 厚み（mm）の指定と変更（初期値: 3mm）
- SVG 全体サイズ（幅）の指定によるリサイズ
- SVG 内のストローク削除オプション
- 指定した塗り色を持つ図形の削除
- STL ファイルの生成とダウンロード

## 使い方

1. `index.html` をブラウザで開きます。
2. 「SVGファイル」から対象のファイルを選択します。
3. 必要に応じて厚みや全体サイズを調整します。
4. ストロークの削除、塗り色の削除オプションを設定します。
5. 「STLを生成」ボタンを押すと、処理が完了後にダウンロードリンクが表示されます。

## 開発・デプロイ

- 本アプリは単一の HTML ファイルのみで構成されており、ビルドステップは不要です。
- Cloudflare Pages にデプロイする場合は、このリポジトリのルートをそのままデプロイ対象に指定してください。

## 注意事項

- 大きな SVG や複雑なパスを含む場合、変換に時間がかかる場合があります。
- STL は非バイナリ形式で生成されます。必要に応じて変換してください。
